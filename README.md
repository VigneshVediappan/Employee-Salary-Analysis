# Employee Salary Analysis

## Aim
To analyze employee salary information using R programming.

## Description
This project stores employee names, departments, and monthly salaries. R calculates annual salaries, average salary, and identifies the highest-paid employee.

## Technologies Used
- R Programming
- Data Frames
- Basic Data Analysis

## Features
- Displays employee information
- Calculates annual salary
- Calculates average monthly salary
- Finds the highest-paid employee

## How to Run
1. Open `02_Employee_Salary_Analysis.R`.
2. Run the program in RStudio or VS Code.
3. Check the output in the R console.

## Result
The program successfully analyzes employee salary data and identifies the highest-paid employee.
